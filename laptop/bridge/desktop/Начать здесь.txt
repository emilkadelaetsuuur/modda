1. В уже открытом Claude Desktop выберите Code → локальный проект → выбрать папку.
C:\Users\User\AppData\Local\ModdaBridge\desktop

2. Разрешите подключение modda в этом проекте. Для одного задания введите /modda.
3. Для демо оставьте окно открытым и введите /loop 2m /modda. Новые заказы берутся с сайта.
4. Откройте ярлык «Открыть MODDA» на рабочем столе.
