# Промпт для агента в браузере (Claude in Chrome или другой): сделать кадры и видео в Google Flow

Перед этим запустите `python -m studio prompts <проект>` (или `make ... --kind cartoon`).
Программа создаст `<проект>/tasks/flow_playbook.md`: там по шагам все промпты, настройки и проверки для этого ролика.
Агенту дайте текст ниже и содержимое flow_playbook.md целиком.

---

Ты работаешь в Google Flow (flow.google.com) во вкладке, где уже открыт нужный аккаунт.
Выполни инструкцию flow_playbook.md (ниже) строго по шагам, сверху вниз.

Жёсткие правила:
1. Промпты из блоков ``` вставляй ДОСЛОВНО и ЦЕЛИКОМ. Ничего не переводи, не сокращай, не улучшай, не пиши свои промпты.
2. Видео делай только режимом «Кадры в видео» (Frames to video) из кадра этого клипа. Никогда не используй текст-в-видео.
3. Сначала сделай ВСЕ кадры (шаг 1) и проверь их (шаг 2). Только потом видео (шаг 3).
4. Перед каждой отправкой проверь на экране: режим, модель, формат (9:16 или 16:9), прикреплённые ингредиенты или первый кадр. Если что-то не так, исправь до отправки.
5. После генерации сверь результат с пунктом «Проверка». Не прошёл: перегенерируй с тем же промптом (до 3 раз).
6. Скачивай каждый файл сразу под именем из инструкции (frames/<id>.png, clips/<id>.mp4).
7. Если что-то идёт не по инструкции (нет кнопки, отказ политики дважды, кончились бонусы), остановись и напиши, на каком шаге и что случилось. Не импровизируй.

Подсказки по интерфейсу Flow (проверено на практике):
- Escape после выбора режима видео сбрасывает режим на картинки. Не нажимай Escape.
- Видео: открыть выбор кадра → поиск по библиотеке → клик по строке (кадр прикрепится сам) → клик в поле промпта → вставить текст → увеличить и проверить, что кадр прикреплён → отправить.
- Скачать: меню карточки «Дополнительные параметры» → «Скачать» → 1K для картинок, 720p для видео.
- Отказ по контент-политике бонусы не списывает. Чаще всего отказывают крупные руки в перчатках при ударе, оружие, огонь у лица.
- Если не грузится скриншот, переключись на вкладку Flow или открой Flow в новой вкладке.
