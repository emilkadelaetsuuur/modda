# Google Flow: Петарды на Новый год: что можно, а за что штраф

## Правила (нарушать нельзя)
1. Промпты копировать ДОСЛОВНО и ЦЕЛИКОМ: не переводить, не сокращать, не дописывать, не придумывать свои.
2. Видео делать ТОЛЬКО режимом «Кадры в видео» (Frames to video) из своего кадра. Текст-в-видео не использовать.
3. Порядок: шаг 0 (референсы), шаг 1 (все кадры), шаг 2 (проверка кадров), шаг 3 (все видео). Не перескакивать.
4. Формат везде 9:16. Картинки: Nano Banana. Видео: Veo 3.1 Lite (или Fast), 8 секунд, 720p, «Вернуть видео без звука».
5. Каждый файл сразу сохранять под указанным именем. Имя = id клипа.
6. Кадр не прошёл проверку: перегенерировать с ТЕМ ЖЕ промптом (до 3 раз). Промпт не менять.

## Шаг 0. Референсы (один раз на аккаунт Flow)
Загрузить в библиотеку Flow (кнопка добавления изображения → Загрузить) и дать понятные имена:
- `assets/refs/abror_face.jpg` → имя «REF abror 1»
- `assets/refs/abror_full.jpg` → имя «REF abror 2»
- `assets/refs/style_bright_sheet.jpg` → имя «REF style bright»
Если эти референсы уже есть в библиотеке, шаг пропустить.

Бонусы вернутся. Перегенерировать один раз. Если снова отказ: для кадра упростить сцену можно ТОЛЬКО в scenario.json (поле scene), затем `python -m studio prompts <проект>` и взять новый промпт. Для видео: удалить клип из списка, монтаж оживит кадр сам.
